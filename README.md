# Имя розы — атлас тайн аббатства

Интерактивное веб-приложение по роману Умберто Эко «Имя розы»: два эталонных плана (аббатство и библиотека) с интерактивными зонами, места смертей, маршруты героев, досье, граф отношений по дням, сравнение судеб, хронология семи дней по каноническим часам, доска улик и версий, исторический контекст и централизованный режим спойлеров.

**Сайт:** `https://<имя-проекта>.pages.dev` (Cloudflare Pages, автоматически из ветки `main`). Как подключить — [DEPLOYMENT.md](DEPLOYMENT.md); как вносить изменения — [CONTRIBUTING.md](CONTRIBUTING.md).

## Запуск

```bash
npm ci               # точные версии из package-lock.json
npm run dev          # http://localhost:5173
npm run lint         # ESLint (без предупреждений)
npm run typecheck    # TypeScript strict
npm test             # целостность данных, спойлеры, локализация, конфигурация развёртывания
npm run build        # сборка сайта в dist/
npm run verify:dist  # проверка сборки: пути, заголовки, внешние запросы, размеры
npm run check        # всё перечисленное подряд — то же, что делает CI
npm run preview:cf   # dist/ в локальной копии Cloudflare Pages (с _headers) на :8788
npm run build:single # один самодостаточный HTML в dist-single/
```

Нужен Node.js 20.19+ (версия для CI и Cloudflare — в `.nvmrc`). Бэкенд, база данных и секреты не нужны: сайт статический, все данные в коде, настройки читателя — в `localStorage` браузера.

## Развёртывание

- **Хостинг:** Cloudflare Pages (бесплатный тариф), Git-интеграция с GitHub: `main` → продакшен, любая другая ветка и PR → предпросмотр.
- **Проверки:** `.github/workflows/ci.yml` — lint, typecheck, test, build, verify:dist, аудит зависимостей; статус `check` обязателен для слияния в `main`.
- **Маршрутизация:** через `#` (`/#/heroes/william`), поэтому обновление страницы и прямые ссылки работают без серверных правил; ресурсы подключаются от корня (`/assets/…`), так что даже неизвестный путь (`/foo/bar`) открывает приложение.
- **Заголовки:** `public/_headers` — строгая CSP (только свой домен), запрет встраивания во фреймы, вечный кэш для `/assets/*`, `noindex` для предпросмотров.
- **Шрифты:** хранятся в `src/assets/fonts` (кириллица + латиница, woff2, OFL) — никаких запросов к Google Fonts; два шрифта первого экрана предзагружаются.
- **Планы:** WebP (аббатство 264 КБ, библиотека 100 КБ; PSNR > 40 дБ относительно исходников).
- **Установка и работа без интернета (PWA):** `public/manifest.webmanifest` и иконки в `public/icons`; при сборке плагин `pwa()` в `vite.config.ts` пишет `dist/sw.js` из `scripts/sw-template.js` со списком всех файлов и версией по их содержимому. Страница — сначала из сети, без сети — из кэша; файлы с хешем — из кэша. После деплоя открытая давно вкладка показывает «Атлас обновился».
- **Метка версии:** в `<meta name="build">` записывается короткий хеш коммита — видно, какая версия опубликована.

## Стек

React 18, TypeScript (strict, `noUncheckedIndexedAccess`), Vite 7, обычный CSS с токенами (светлая и тёмная тема), Lucide для иконок, собственные SVG-карта и граф без графовых библиотек, Vitest 4, ESLint 9.

## Визуальная система

Палитра ограничена тремя цветами: чёрный (фон, глубина), слоновая кость (текст, линии, листы с подробностями) и бордовый (смерть, выбор, маршруты, ключевые связи). Остальное — оттенки серого. Раскрытые сведения появляются на светлом «листе рукописи» поверх тёмного аббатства.

Движение задано токенами в `src/styles.css` (`--t-fast` 180 мс, `--t-medium` 320 мс, `--t-slow` 650 мс, `--t-dramatic` 1400 мс; кривые `--ease`, `--ease-out`, `--ease-in-out`) и зеркально в `src/lib/motion.ts`.

- Главная: вступление ≈3,4 с (линии аббатства → IL NOME DELLA ROSA → «Имя розы» → бордовая точка и маршрут → вход). При повторном визите показывается сразу.
- Карта: при первом открытии за сессию схема прорисовывается (контур → здания → подписи → знаки), потом — короткое проявление. Наведение высветляет помещение и приглушает остальные; выбор проводит линию к панели; клик по смерти плавно переводит камеру.
- Маршруты рисуются отрезок за отрезком; путь Адсона идёт поверх бледного пути Вильгельма.
- Граф раскрывается волнами от центрального героя; начертание линии зависит от типа отношения.
- Хронология: при смене дня старые события уходят, новые появляются по очереди; при переходе с карты событие отмечается.
- `prefers-reduced-motion`: вступление, прорисовка, пульс и ожидания отключаются.

## Режим спойлеров

Каждая сущность и каждый фрагмент текста имеют `revealDay` (0–7) и, при необходимости, `critical` (раскрывает разгадку).

- **Без спойлеров** — завязка и первый день.
- **По ходу чтения** — всё до выбранного дня; разгадка — только с седьмого.
- **Всё расследование** — всё сразу (с предупреждением).

Режим влияет на карту (какие смерти видны, какой знак у маркера, место фактической смерти), граф (узлы, фазы связей), хронологию, досье, доску улик, справки и даже список источников. Знак маркера смерти до разгадки — «обстоятельства не выяснены», поэтому характер смерти не выдаётся цветом.

## Карты

Карты — это эталонные изображения, поверх которых лежит выровненный SVG-слой зон. У каждого плана своя система координат (пиксели изображения), связь между ними явная: зона Эдифиция открывает план библиотеки, кнопка «К Эдифицию» возвращает назад. По умолчанию план показан в ночной гамме: яркость инвертирована фильтром, красные буквы плана библиотеки окрашены бордовым. Переключатель «Исходный скан» показывает оригинал. Подробности обводки и расхождения легенды — в `content-sources.md`.

## Адреса

`#/map?view=library&loc=finis-africae` · `#/map?spot=ab-K` · `#/map?route=william&step=3` · `#/heroes/jorge` · `#/relations?focus=malachi&upto=5` · `#/compare?a=william&b=adso` · `#/timeline?event=e-malachi-death&f=death` · `#/clues?h=h-apocalypse` · `#/history/h-poverty`. Адреса переживают перезагрузку. Короткие якоря `#map`, `#heroes` тоже работают.

## Расширение контента

Добавьте объект в нужный файл `src/data/*.ts`, ссылаясь на другие сущности по `id`, и запустите `npm test`: тест целостности укажет на любую битую ссылку, а тест спойлеров — на текст, который раскрывает разгадку слишком рано.
